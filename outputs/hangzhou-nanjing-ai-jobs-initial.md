# 杭州 / 南京 AI 岗位初步调查

调查日期：2026 年 11 月 2 日
目标：杭州优先，南京备选；税前 6–10K 优先；接受线下办公、客户沟通和短期出差。

## 结论

当前最适合的切入口是：

1. AI 应用实施 / Agent 实施 / AI 交付工程师
2. Python + AI 应用开发初级岗位
3. AI 解决方案助理 / AI 产品应用岗位

暂时不应把主要目标放在纯大模型研发、高级 Agent 开发或要求 3–5 年生产经验的岗位上。

## 你的岗位定位

当前能力更适合被包装为：

> 能使用 Dify、Ollama 和 AI 编程工具快速完成企业 AI 应用原型，并具备继续补齐 Python、接口、部署和交付能力的 AI 应用实施 / Agent 交付候选人。

简历中不能只写“会使用 ChatGPT、Codex、Dify 和 Ollama”。需要写成可验证的项目成果，例如：

- 搭建了可运行的企业知识库问答应用；
- 支持文档检索、引用依据和结构化输出；
- 通过 FastAPI 封装模型或业务接口；
- 使用 Docker Compose 完成部署；
- 建立测试问题集并记录失败案例；
- 能根据日志定位接口、端口、模型和环境变量问题。
