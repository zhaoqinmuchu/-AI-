# 总控窗口周度同步检查表

使用周期：每周一次，建议在下一周课程冻结前完成。

## A. 市场事实

- [ ] 招聘窗口已生成本周市场快照；
- [ ] 新岗位都有来源链接；
- [ ] 详情已核实和搜索确认已区分；
- [ ] 企业线索没有被算成单个岗位；
- [ ] 实习、校招和过期岗位已单独标记；
- [ ] 杭州和南京样本数量已统计；
- [ ] 没有重复岗位或重复公司证据；

## B. 技能证据

- [ ] 技能已区分硬要求、职责要求和加分项；
- [ ] 技能已标明 A/B/C 岗位相关性；
- [ ] 技能已标明独立公司数量；
- [ ] 动态技能满足 3 条独立证据规则后才进入候选；
- [ ] 长周期技能没有挤压固定核心；

## C. 训练进度

- [ ] 当前周固定课程按冻结计划执行；
- [ ] 每节课有解释题；
- [ ] 每节课有独立复现；
- [ ] 每节课有迁移题；
- [ ] 每节课有可保存成果；
- [ ] 未通过内容已经记录补课方式；
- [ ] 没有把“执行过命令”当成“已经掌握”；

## D. 项目和环境

- [ ] Node 测试状态已更新；
- [ ] 离线评测状态已更新；
- [ ] FastAPI 是否实际启动已明确；
- [ ] Docker/Compose 是否实际启动已明确；
- [ ] Ollama/Dify 是代码适配还是实际联调已区分；
- [ ] 项目新增功能没有超过当前课程范围；

## E. 决策

- [ ] 下一周固定核心课不变或有明确调整理由；
- [ ] 动态课程有证据依据；
- [ ] 没有把单个岗位需求直接加入主线；
- [ ] 已写入周度决定；
- [ ] 已更新课程冻结记录；
- [ ] 已记录下一次同步时间；
