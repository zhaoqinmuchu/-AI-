## 可以进入固定核心的共同能力

- Python 和 API 集成；
- JSON、HTTP、REST 和接口联调；
- RAG、Agent 和 Workflow；
- 结构化输出、评测和人工复核；
- 部署、日志、端口和环境变量；
- 需求梳理、UAT、验收和交付文档；
- 客户沟通和问题排查。

## 动态技能观察清单

- Dify、Coze、FastGPT：有企业线索，但缺少足够的独立、适合用户的详情岗位；
- LangChain、LangGraph、LlamaIndex：主要来自实习、校招或参考资料；
- SQL/MySQL/Redis：出现于参考岗位和技能模型，杭州南京有效详情不足；
- RPA/n8n：南京企业线索明确，但尚未形成具体岗位证据；
- TypeScript：杭州 AI 全栈方向有线索，但样本数量不足；
- C/C++：有终端 Agent 和 CAD FDE 方向，但不应打断 AI 应用主线。

## 当前课程决定

1. Python、API、RAG、Agent、部署、交付继续作为固定核心；
2. 动态课程槽位暂不新增具体框架；
3. 动态槽位优先用于当前核心的复习、迁移和岗位匹配；
4. C/C++ 和 CAD API 放长期路线；
5. 下一次市场同步后，如果出现 3 条独立详情岗位明确要求同一动态技能，再重新评估。

## 数据限制

当前样本数量尚未达到原计划的杭州 50 条、南京 25 条；其中部分记录不是详情已核实岗位。因此本快照可以决定固定核心方向，但不能决定具体框架专项或长期技能投入。
