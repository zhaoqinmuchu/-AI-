# 当前优先岗位匹配卡

## 卡片 A：杭州华途信息安全｜服务端 AI 全栈开发工程师

- 原始详情：[杭州电子科技大学就业平台](https://job.hdu.edu.cn/job/view/id/1731866)
- 城市：杭州西湖
- 薪资：8–13K
- 学历：本科
- 经验：不限
- 当前等级：B+，优先核实

### 岗位可能关注

- 服务端开发；
- AI 应用接口；
- Python 或其他后端语言；
- 模型/API 集成；
- 业务系统联调；
- 服务启动和问题排查。

### 你已有的证据

- 企业 AI 工作台已能运行；
- 有知识库问答和引用依据；
- 有工程审查和结构化输出；
- 有工具调用；
- 有 Ollama 和 Dify 适配；
- 有 20 条离线评测；
- 有 Node 服务和接口设计。

### 需要补齐

- Python 基础；
- FastAPI 实际启动；
- JSON/HTTP/REST API 解释；
- 数据库和简单 SQL；
- Linux、日志和端口排错。

### 作品集要展示

一个完整流程：文档导入 → 检索 → 模型回答 → 引用 → 工具调用 → 人工复核 → 失败回退。

### 手动核实问题

1. 实际后端语言和框架是什么？
2. AI 应用属于安全产品、知识库还是内部业务系统？
3. “经验不限”是否接受跨专业毕业两年半的候选人？
4. 是否需要出差、驻场或客户沟通？
