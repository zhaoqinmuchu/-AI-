# 24 节课练习与验收清单

这份清单是教材的操作版。每节课最多三个新概念。具体命令不会一次全部发给你，而是在互动教学中按当前课次逐步发放。

## 每节课的固定流程

1. 先回答一个预测问题；
2. 学习本节三个概念；
3. 跟着完成最小案例；
4. 处理一个变式或错误；
5. 不看完整步骤复述；
6. 保存证据并更新状态。

## 每周关卡

### 第 1 周关卡：解释一次请求

给出“杭州出差住宿超过标准怎么办？”，你要能画出请求链路，指出知识库依据、回答结果、人工复核和执行轨迹。

### 第 2 周关卡：独立写业务规则

不给完整代码，只给“费用 680 元，标准 450 元，超过标准要人工复核”，你要能写出或让 Codex 生成一个可运行脚本，并解释每个字段。

### 第 3 周关卡：处理 API 错误

面对空标题、错误 JSON、错误路径和模型地址错误，你要能区分输入错误、地址错误和服务故障。

### 第 4 周关卡：做三问 RAG 评测

准备一个有依据问题、一个无依据问题和一个涉及版本的问题，记录引用、状态和处理方式。

### 第 5 周关卡：设计一个工作流

把“审查工程安全隐患”拆成输入、检索、风险、工具、人工复核和输出字段。

### 第 6 周关卡：对照两种后端实现

指出 Node 和 FastAPI 版本的路径、请求字段、响应字段和错误处理差异。

### 第 7 周关卡：完成一次故障排查

处理端口占用或模型服务地址错误，写出问题、证据、判断、修复和复测。

### 第 8 周关卡：模拟客户和面试官

先完成一份交付验收清单，再用 3 分钟讲项目，并根据三个不同岗位改写项目重点。

## 教学中的暂停规则

出现以下任一情况，下一轮不增加新概念：

- 你能照做但说不出这一步解决什么问题；
- 你能说定义但不能指出项目中的对应位置；
- 你能完成正常案例但不能解释错误结果；
- 你能解释项目但不能迁移到一个新输入。

暂停不是返工整章，而是针对缺失点追加一个小练习，通常只补一个概念或一个变式。
