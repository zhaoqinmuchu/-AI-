# Python 学习路线：从看懂到能交付

目标不是背完 Python，而是能看懂、修改、调试和验收 AI 应用代码。

## 三层掌握范围

### 必须能自己写出

- 变量、字符串、数字、布尔值和 `None`；
- 列表和字典；
- `if / elif / else`；
- `for`；
- 函数和 `return`；
- `try / except`；
- `import`；
- `os.getenv`；
- `json`；
- 基础文件读取。

### 必须能看懂并修改

- `class`；
- 类型注解；
- `async / await`；
- `with`；
- 装饰器；
- Pydantic 模型；
- FastAPI 路由；
- `Path`；
- HTTP 客户端；
- 数据库查询。

### 暂时只需认识

- 元类；
- 描述符；
- 生成器底层机制；
- 自定义装饰器；
- 复杂继承；
- 魔术方法；
- 高级并发模型；
- Python 内存模型。

## 五阶段路线

### 阶段一：看懂数据

概念：变量、字典、列表。

案例：费用申请、岗位信息和知识库文档。

目标：能读取和修改 `job["city"]`、`document["title"]` 这类字段。

### 阶段二：做业务判断

概念：`if`、函数、`return`。

案例：费用是否超过标准。

目标：能写出正常结果和人工复核结果。

### 阶段三：处理错误和配置

概念：`try/except`、类型转换、环境变量。

案例：缺少金额、金额不是数字、模型名称从环境变量读取。

目标：能区分输入错误、配置错误和业务复核。

### 阶段四：调用 API

概念：JSON、请求/响应、状态码。

案例：调用工作台的问答、文档导入和工具接口。

目标：能解释请求字段、响应字段和错误状态。

### 阶段五：阅读 FastAPI

概念：路由、请求模型、参数校验。

案例：阅读并启动 FastAPI 适配层。

目标：能阅读、修改和验收 FastAPI 接口，不要求一开始独立设计大型后端。

## 每节 Python 课的教学循环

1. 先看一个业务案例；
2. 只讲三个概念；
3. 完成 10–20 行最小代码；
4. 只修改一个字段或判断；
5. 故意加入一个错误；
6. 用自己的话解释输入、输出和错误。

## Python 通过标准

- 能写一个费用判断函数；
- 能构造字典和列表；
- 能读取 JSON 字段；
- 能使用条件判断；
- 能处理异常；
- 能读取文件和环境变量；
- 能阅读 FastAPI 基础路由；
- 能使用 Codex 修改代码后自行验收。
