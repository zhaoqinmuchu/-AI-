# AI 应用实施与 Agent 交付：学习目标与掌握清单

版本：0.2

这份文件是课程的总验收表。教材不是要求“看完”，而是要求每一项能力达到指定等级。

## 掌握等级

| 等级 | 含义 | 验收方式 |
|---|---|---|
| L1 认识 | 能用自己的话解释是什么、解决什么问题 | 不看教材口头解释 |
| L2 跟做 | 能按照步骤完成一次操作 | 跟着命令或提示完成案例 |
| L3 独立 | 不看完整步骤也能完成，并能处理一个常见错误 | 独立完成变式案例 |
| L4 迁移 | 能把能力用于新岗位、新业务或面试追问 | 新案例、岗位匹配卡、面试演练 |

8 周结束时，核心能力目标为 L3；求职表达和项目交付目标为 L4。Docker 的实际启动如果受本机环境限制，目标先记为 L2+：能解释结构、按步骤启动、能排查基本错误，等环境具备后补 L3。

## 不纳入 8 周主线的内容

以下内容不影响当前主线达标：深度学习训练、模型微调、复杂多 Agent、Kubernetes、Linux 内核、高级数据结构、CAD API、SolidWorks/CATIA/UG 二次开发。

如果岗位调查显示某个具体岗位把其中一项列为硬要求，再单独开支线，不打断主线课程。

## 每节课的通过条件

一节课不能只看懂，也不能只把命令运行成功。必须同时满足：

1. 能说出本节最多三个新概念的含义；
2. 能完成本节案例的基本操作；
3. 能解释一次结果或错误；
4. 能回答一个变式问题；
5. 能留下一个证据文件、接口结果、截图文字或口头回答。

如果只完成操作但无法解释，课程状态为“操作完成、理解未通过”；下一轮先补解释，不继续堆新内容。
